# Política de Segurança

## Versões Suportadas

Este projeto está atualmente em desenvolvimento. A versão mais recente disponível no repositório é a versão suportada e recebe correções e atualizações de segurança.

## Relato de Vulnerabilidades

Se você identificar uma possível vulnerabilidade de segurança neste projeto, não publique informações sensíveis, senhas, chaves, tokens ou outros dados privados em uma Issue pública.

Utilize os recursos de relatório privado de vulnerabilidades disponibilizados pelo GitHub para comunicar o problema de forma responsável.

Ao relatar uma vulnerabilidade, informe, sempre que possível:

- Uma descrição clara do problema;
- As etapas necessárias para reproduzi-lo;
- O possível impacto da vulnerabilidade;
- Sugestões de correção, caso existam.

As vulnerabilidades relatadas serão analisadas e tratadas de acordo com sua gravidade.

## Boas Práticas de Segurança

Este projeto procura seguir boas práticas de segurança, incluindo:

- Proteção de dados sensíveis;
- Uso de variáveis de ambiente para credenciais e chaves;
- Monitoramento de dependências;
- Análise de vulnerabilidades;
- Proteção contra exposição de segredos;
- Atualizações periódicas das dependências.

Obrigado por contribuir para a segurança do projeto.
